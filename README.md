# Catppuccin Latte for MikuTV

Soothing pastel mauve and crisp porcelain daytime palette inspired by Catppuccin Latte for MikuTV.

- **Plugin ID**: `catppuccin-latte`
- **Kind**: `theme` (`light` appearance, daytime pair for **Catppuccin Mocha**)
- **Version**: `1.0.0`
- **License**: Apache-2.0

## Installation

1. Open **MikuTV** on Apple TV.
2. Go to **设置 → 外观与动态 → 白天主题 → 发现更多主题** (or **设置 → 插件管理 → 发现插件**).
3. Select **Catppuccin Latte** (`yuchanns/mikutv-theme-catppuccin-latte`) and install.
